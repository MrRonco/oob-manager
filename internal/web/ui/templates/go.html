Keyboard shortcuts

These need scripts. They never act while you type in a field, and they are off on a connected console page, so the remote host gets every key.

Ctrl+K, ⌘+K on a Mac
Open Go to as a palette: type to filter, ↑ ↓ to move, Enter to open, Escape to close.
/
Jump to the page's filter field (Events, Firmware, the audit log, this page); on a page without one, open the palette.
g then o
Overview.
g then s
Servers.
?
This list of shortcuts.

The palette also lists the tabs of the server you are on and the last pages you opened in this browser tab (kept only until the tab closes).
