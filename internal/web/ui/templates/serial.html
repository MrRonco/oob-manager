Connected, but the host has sent nothing yet. Press Enter to wake a login prompt. If the screen stays blank, the host is not using the BMC's serial port: turn on BIOS serial redirection to COM2 and a serial console on the operating system (console=ttyS1,115200n8 on Linux), then reboot the host.

The keyboard goes to the host while the terminal has focus. Press Ctrl+Alt+Shift to return focus to the toolbar. A typed Ctrl+\ is not sent (it would end the BMC console); use the toolbar instead.
